## être — Présent

**Q21. It is (impersonal)**  
_Impersonal 'it' with être uses ce, not il or elle_

- Il est — This is 'he is' — a person, not an impersonal 'it'.
- **C'est** ✓ — Correct! 'C'est' is the impersonal 'it is'.
- Elle est — This is 'she is' — a person, not an impersonal 'it'.
- Ce sont — This is 'these are' — plural, not singular.

**Q22. It is not (impersonal)**  
_Negative of the impersonal c'est — ne ... pas around est_

- Il n'est pas — This is 'he is not' — a person.
- Elle n'est pas — This is 'she is not' — a person.
- Ce ne sont pas — This is 'these are not' — plural.
- **Ce n'est pas** ✓ — Correct! 'Ce n'est pas' is the impersonal 'it is not'.

**Q23. It is easy**  
_Impersonal c'est in the present tense_

- Ce sera facile — This is 'it will be easy' — future, not present.
- Ce sont faciles — This is 'they are easy' — plural.
- **C'est facile** ✓ — Correct! 'C'est facile' is 'it is easy'.
- Ce n'est pas facile — This is 'it is not easy' — negative.

**Q24. It is not difficult**  
_Negative impersonal c'est with an adjective_

- **Ce n'est pas difficile** ✓ — Correct! 'Ce n'est pas difficile' is 'it is not difficult'.
- C'est difficile — This is 'it is difficult' — affirmative, not negative.
- Il n'est pas difficile — This is 'he is not difficult' — a person.
- Ce ne sera pas difficile — This is 'it will not be difficult' — future.

**Q25. These are / They are (things)**  
_Plural of the impersonal ce with être_

- C'est — This is 'it is' — singular.
- Ils sont — This is 'they are' for people or masculine nouns, not the presenting 'these are'.
- **Ce sont** ✓ — Correct! 'Ce sont' is the plural of 'c'est'.
- Ce seront — This is 'these will be' — future.

## avoir — Présent

**Q21. There is / There are**  
_The fixed expression for 'there is' uses avoir with y_

- Il a — This is 'he has' — a person possessing something.
- Ils ont — This is 'they have'.
- **Il y a** ✓ — Correct! 'Il y a' is 'there is' or 'there are'.
- Il y aura — This is 'there will be' — future.

**Q22. There is not / There isn't**  
_Negative of il y a — ne ... pas around a_

- **Il n'y a pas** ✓ — Correct! 'Il n'y a pas' is 'there is not'.
- Il n'a pas — This is 'he does not have'.
- Il n'y aura pas — This is 'there will not be' — future.
- Il y a — This is 'there is' — affirmative.

**Q23. There is a problem**  
_Il y a with a singular noun_

- Il a un problème — This is 'he has a problem' — a person.
- Ils ont un problème — This is 'they have a problem'.
- Il y aura un problème — This is 'there will be a problem' — future.
- **Il y a un problème** ✓ — Correct! 'Il y a un problème' is 'there is a problem'.

**Q24. There is nothing**  
_Il y a with rien — ne goes before y_

- Il n'a rien — This is 'he has nothing' — a person.
- **Il n'y a rien** ✓ — Correct! 'Il n'y a rien' is 'there is nothing'.
- Il n'y aura rien — This is 'there will be nothing' — future.
- Il y a rien — This drops the 'ne' — heard in speech but incorrect in written French.

**Q25. There are three books**  
_Il y a does not change for plural nouns_

- Il a trois livres — This is 'he has three books'.
- Ils ont trois livres — This is 'they have three books'.
- **Il y a trois livres** ✓ — Correct! 'Il y a' stays the same whether one thing or many.
- Il y aura trois livres — This is 'there will be three books' — future.

## avoir — Passé Composé

**Q21. There was / There has been**  
_Passé composé of il y a — the past participle is eu_

- Il a eu — This is 'he had' — a person.
- **Il y a eu** ✓ — Correct! 'Il y a eu' is 'there was' or 'there has been'.
- Il y a — This is 'there is' — present.
- Ils ont eu — This is 'they had'.

**Q22. There was not / There has not been**  
_Negative passé composé of il y a_

- Il n'a pas eu — This is 'he did not have'.
- Il n'y a pas — This is 'there is not' — present.
- Ils n'ont pas eu — This is 'they did not have'.
- **Il n'y a pas eu** ✓ — Correct! 'Il n'y a pas eu' is 'there was not'.

**Q23. There was a problem**  
_Il y a eu with a singular noun_

- **Il y a eu un problème** ✓ — Correct! 'Il y a eu un problème' is 'there was a problem'.
- Il a eu un problème — This is 'he had a problem' — a person.
- Il y a un problème — This is 'there is a problem' — present.
- Il y aura un problème — This is 'there will be a problem' — future.

**Q24. There was an accident**  
_Il y a eu reporting a past event_

- Il a eu un accident — This is 'he had an accident' — a person.
- Il y a un accident — This is 'there is an accident' — present.
- **Il y a eu un accident** ✓ — Correct! 'Il y a eu un accident' is 'there was an accident'.
- Ils ont eu un accident — This is 'they had an accident'.

**Q25. There has been nothing**  
_Rien sits between the auxiliary and the participle_

- Il n'a rien eu — This is 'he had nothing' — a person.
- **Il n'y a rien eu** ✓ — Correct! 'Il n'y a rien eu' is 'there has been nothing'.
- Il n'y a rien — This is 'there is nothing' — present.
- Il n'y aura rien — This is 'there will be nothing' — future.

## faire — Présent

**Q21. It is cold (the weather)**  
_Weather uses faire, not être or avoir_

- Il est froid — This describes an object as cold, not the weather.
- **Il fait froid** ✓ — Correct! Weather takes faire: 'il fait froid'.
- Il a froid — This is 'he is cold' — a person feeling cold.
- Il fera froid — This is 'it will be cold' — future.

**Q22. It is hot (the weather)**  
_Weather uses faire — compare 'il a chaud' for a person_

- Il a chaud — This is 'he is hot' — a person feeling hot.
- Il est chaud — This describes an object as hot, not the weather.
- Il fera chaud — This is 'it will be hot' — future.
- **Il fait chaud** ✓ — Correct! Weather takes faire: 'il fait chaud'.

**Q23. The weather is nice**  
_Il fait beau is the fixed expression for good weather_

- **Il fait beau** ✓ — Correct! 'Il fait beau' is 'the weather is nice'.
- Il est beau — This is 'he is handsome' — a person.
- Il fera beau — This is 'the weather will be nice' — future.
- Il a fait beau — This is 'the weather was nice' — passé composé.

**Q24. It is not cold (the weather)**  
_Negative weather expression — ne ... pas around fait_

- Il n'a pas froid — This is 'he is not cold' — a person.
- Il n'est pas froid — This describes an object, not the weather.
- **Il ne fait pas froid** ✓ — Correct! 'Il ne fait pas froid' is 'it is not cold'.
- Il ne fera pas froid — This is 'it will not be cold' — future.

**Q25. It is night / It is dark**  
_Time of day also takes faire_

- Il est nuit — Nuit takes faire, not être.
- **Il fait nuit** ✓ — Correct! 'Il fait nuit' is 'it is night' or 'it is dark'.
- Il fera nuit — This is 'it will be dark' — future.
- Il a fait nuit — This is 'it was dark' — passé composé.

**Q24. It was not cold (the weather)**
